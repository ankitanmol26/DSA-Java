 ## How to actually study each topic

 This is **more important than the roadmap itself**.

 For every topic:

 ### Step 1 — Learn

 Watch the concept explanation.

 For example, for Arrays:

 > Traversal → hashing → two pointers → sliding window → prefix sum → Kadane

 ### Step 2 — Implement

 Write the technique yourself.

 Don't just watch someone code it.

 ### Step 3 — Easy problems

 Solve **3–5 easy problems** without looking at solutions.

 ### Step 4 — Medium problems

 Solve **5–10 medium problems**.

 For each problem:

 **20–30 min struggle → then study the solution → close it → code it yourself.**

 Don't spend 2 hours staring at one problem.

 ### Step 5 — Pattern notes

 Keep a very small notebook:

```
Two pointers:
When → sorted array / pair / opposite ends
Idea → maintain left and right
Complexity → usually O(n)

Sliding window:
When → contiguous subarray/substring
Idea → expand + shrink window
```

 This becomes your **interview revision material**.
